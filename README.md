# Public Data


### Dataset Websites

Many websites which host datasets, these are some;

- [Kaggle.com](https://www.kaggle.com/) is full of sample data!

- [FiveThirtyEight.com](https://data.fivethirtyeight.com/) has lots of neat data sets

- The [github awesomedata repository](https://github.com/awesomedata/awesome-public-datasets) has a collection of interesting data sets

- [Wikipedia](https://en.wikipedia.org/wiki/List_of_datasets_for_machine-learning_research) has a list of datasets for machine learning research

- [SqlSkills.com](https://www.sqlskills.com/sql-server-resources/sql-server-demos/) publishes sample databases for SQL Server, which include some corrupt databases so you can practice recovery operations

- [London Open Data](https://opendata.london.ca/)

- [New York City Open Data](https://opendata.cityofnewyork.us/)

- [Seattle Open Data](https://data.seattle.gov/)

- [Tokyo open data](https://portal.data.metro.tokyo.lg.jp/) (in Japanese, obviously)

- Find open data at [data.gov.uk](https://www.data.gov.uk/)
